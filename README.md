# 晚安收容所 SleepAnomaly

> 诡异萌收容所题材的睡眠打卡：睡前布置结界，晨起提交结界报告，把夜里作乱的收容物收容进档案。≥2 分收容成功、≥6 分档案标注「异常听话」；契约（言出必行）达标 +3。伪档案腔×Q版诡异萌，绝不吓人。

- 在线体验：<https://thricenope.github.io/sleep-anomaly/>（数据存在浏览器本地，换设备请用应用内导出/导入）
- 技术栈：Vite + React 18 + TypeScript + zustand(persist) + framer-motion，纯前端 localStorage
- 本地开发：`npm install && npm run dev` → http://localhost:5196

## 玩法

1. 睡前布置「结界」：几点上床 / 手机怎么安排（即改即存）
2. 晨起交「结界报告」：几点睡着 / 时长 / 夜醒 / 晨起状态 / 运动
3. 点「夜巡！」——评分即收容强度，≥2 收容成功、≥6 异常听话
4. 守夜资历推进，收容档案收录 6 个收容物（周末 BOSS 收容物零号·"睡不着"）
5. 研究所看统计；数据可导出/导入
